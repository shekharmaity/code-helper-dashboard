# Mock Dashboard (React)

This is a starter React (Vite) dashboard for managing a Quarkus Dynamic Mock Server.

## Setup

1. Install dependencies:
   ```
   npm install
   ```

2. Start dev server:
   ```
   npm run dev
   ```

3. The app will run at http://localhost:3000

## Notes

- The frontend expects the Quarkus admin API at `http://localhost:8080/admin/mocks`.
- You can change the API base URL in `src/api/mocks.js`.
